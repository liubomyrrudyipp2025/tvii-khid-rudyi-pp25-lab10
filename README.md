# Твій Хід — ЛР10

Рудий Л. Д., ПП-25. Поточна накопичувальна версія навчального сайту «Твій Хід» на етапі ЛР10: функції попередніх лабораторних доповнено динамічними медіакомпонентами з прототипу Bolt/StackBlitz. Папки й релізи ЛР1–9 — історичні знімки, а не окремі незалежні продукти; невідомі завдання ЛР11–12 наперед не реалізуються.

## Компоненти

- Повернуті з реально випущеної ЛР6: три навчальні картки з характеристиками й поясненням рекомендації; локальний пошук за назвою, стан відсутності результатів; додавання/видалення в демо-кошику, узгоджені лічильники та reset після reload. Жодного оформлення, backend, мережевого надсилання або збереження вибору.
- Накопичувальна навігація: desktop «Сервіс», mobile native menu з Escape/outside dismissal та поверненням фокуса; прямі переходи до форми, карти, Smart Select і прикладів. Desktop header закріплюється від 1100 px, якірні переходи мають відступ; skip-link явно фокусує main, вибрана radio-картка виділяється в обох темах.
- Статичні інформаційні блоки з ЛР5–6: разова покупка, подарунок і Smart Select з полями ціни/складу/умов без вигаданих значень; чотири концептуальні дії підписки з явно недоступним керуванням.

- Повна темна/світла тема: палітра ЛР3, клавіатурний перемикач; зберігається лише вибір теми.
- Hero: 8 окремих варіантів — горизонтальні та вертикальні фото й відео для темної і світлої тем. Комп’ютер використовує горизонтальні ресурси, телефон (до 767 px) — вертикальні. Фото за замовчанням — відповідний макет ЛР3, а не відеопостер. Відео завантажується лише після вибору, без звуку; мобільні кліпи 9:16 показуються повністю, без обрізання або розтягування.
- Основа коробки у восьми варіантах Hero має узгоджені положення й масштаб за початковим кадром: застосовано рівномірну CSS-підгонку оригіналів. На телефоні навмисно залишаються смуги фону, щоб показати джерела повністю; на комп’ютері збережено фонове cover-полотно з обрізанням країв. Карти, жетони й рух усередині різних оригіналів не стають тотожними; це не обіцянка піксельної однаковості всієї анімації.
- «Ігрові вечори»: три ілюстративні фото Pavel Danilyuk / Pexels через офіційний CDN, одне повне фото на будь-якій ширині, ручна навігація без автопрокрутки. Оригінали фото не поширюються у проєкті; потрібна мережа. Джерела — `CREDITS.md`.
- YouTube: англомовний огляд «Top 10 Essential Board Games Everyone Should Own» — Board Game Hangover.

- Swiper 11.2.10: шість явно вигаданих відгуків, 1/2/3 видимі слайди, loop, autoplay 3500 мс, стрілки, пагінація й ручна пауза. Hover, фокус, прихована вкладка та reduced-motion зупиняють автоматичне відтворення.
- GLightbox 3.3.1: кнопка «Збільшити ілюстрацію» у режимі фото Hero відкриває чотири наявні варіанти графіки ЛР3 (три оригінальні JPEG і світлу мобільну ілюстрацію у WebP), модальний перегляд і навігація. Це альтернатива Fancybox, а не використання Fancybox; погодження заміни викладачем не заявляється.
- Typed.js 2.0.12: три фрази в Hero, керування паузою та статичний доступний текст. Після переходу до reduced-motion залишається безпечний статичний варіант до перезавантаження.
- Успадкована форма: п’ять чистих валідаторів, стани полів, нативний діалог, Escape, повернення фокуса та reset.

Версії зовнішніх бібліотек зафіксовані в CDN-адресах. Для анімованих компонентів потрібен доступ до CDN; за його відсутності залишається статичний текст/зображення. CSS Tailwind 3.4.17 компілюється локально: Play CDN у production не використовується.

Масштаб галереї залежить від режиму GLightbox: на desktop click-zoom збільшує зменшені зображення, але не розтягує вже показані 1:1. На ширинах до 768 px використовується pinch-zoom. У pinned GLightbox 3.3.1 після переходів між слайдами повернення до початкового розміру може потребувати сильнішого зведення пальців, а не строго симетричного жесту. Swipe працює між сусідніми зображеннями, а циклічний перехід через край альбому — кнопками навігації.

## Локальний запуск

Потрібні Node.js >=18 із npm та Python >=3.11. У VS Code налаштовано Live Server на `127.0.0.1:5510`, без автоматичного відкриття браузера. Відкрийте `index.html` та виконайте `Live Server: Open with Live Server`.

Окремий запуск зібраного сайту без розширення Live Server:

```bash
npm ci
npm run package:dist
python -m http.server 5511 --bind 127.0.0.1 --directory dist
```

Адреса цього окремого сервера: `http://127.0.0.1:5511/`.

```bash
python -m unittest discover -s tests -v
node --test tests/validation.test.cjs
```

Тести джерел і валідаторів не замінюють перевірку взаємодій у браузері. Автоматизований viewport не є фізичним пристроєм або ручним screen-reader тестуванням.

## Приватність і межі прототипу

Форма не має backend/API: введення не надсилається, не зберігається й не журналюється. Використовуйте лише вигадані дані. Телефон перевіряється буквально як `+380` та дев’ять ASCII-цифр, без trim/маски; ім’я й повідомлення рахуються графемами. Success dialog прямо повідомляє, що дані не надсилалися.

Замовлення, оплата, доставка, підписка та повний квіз не реалізовані. Фото Pexels, карта, YouTube й Time.is — окремі сторонні ресурси із власними запитами; це не надсилання форми. Sandbox годинника залишається `allow-scripts allow-popups`, без `allow-same-origin`. Ліцензії успадкованих ресурсів збережені в assets.

Пакувальник копіює тільки runtime-allowlist, зокрема `js/theme.js`, `js/media-components.js`, `css/media-components.css` та `CREDITS.md`. Звіти, чати, prompts, резервні копії, приватні докази, тести й конфігурація IDE до сайту не входять.
